# Hosting Task Module Documentation

This directory contains architecture and design documentation for the Task queue and execution submodule.

## Files

- **task-d11-sad.md** - System Architecture Document for Drupal 11 version (current)
- **task-d7.md** - Legacy documentation for Drupal 7 version (source code no longer in this repository)

## Note on Drupal 7 Documentation

Files ending in `-d7.md` are preserved for historical reference and migration guidance. The Drupal 7 source code is not present in this codebase - this is a Drupal 11+ implementation.
